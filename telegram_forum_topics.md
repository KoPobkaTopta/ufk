# Топики (Forum Topics) в Telegram Bot API

## Что это?

**Топики** — это функция **супергрупп** в Telegram, которая позволяет разделить один групповой чат на несколько тематических веток (как на форуме). Бот может программно создавать, редактировать, закрывать и удалять эти топики через Bot API.

Чтобы топики работали, у группы должна быть включена настройка **«Темы»** (Topics) — это доступно только для супергрупп.

## Зачем боту топики?

### 1. Организация общения
Вместо одного общего потока сообщений бот может раскидывать информацию по категориям:
- «Объявления»
- «Вопросы и ответы»
- «Баг-репорты»
- «Домашние задания»

### 2. Тикет-система / поддержка
Бот может создавать **отдельный топик на каждого пользователя** или на каждый тикет. Это удобно для саппорт-ботов: каждый запрос — свой топик, история не теряется.

### 3. Уведомления по категориям
Бот-нотификатор может отправлять алерты в разные топики:
- CI/CD результаты → топик «Деплой»
- Мониторинг → топик «Алерты»
- Логи → топик «Логи»

### 4. Автоматическая модерация
Бот может закрывать/открывать топики по расписанию или по событиям (например, закрывать обсуждение после дедлайна).

## Основные методы API

| Метод | Что делает |
|---|---|
| `createForumTopic` | Создаёт новый топик в супергруппе |
| `editForumTopic` | Меняет название и иконку топика |
| `closeForumTopic` | Закрывает топик (нельзя писать) |
| `reopenForumTopic` | Открывает закрытый топик обратно |
| `deleteForumTopic` | Удаляет топик вместе со всеми сообщениями |
| `unpinAllForumTopicMessages` | Открепляет все сообщения в топике |
| `getForumTopicIconStickers` | Получает список стикеров для иконок топиков |
| `editGeneralForumTopic` | Редактирует «Общий» (General) топик |
| `closeGeneralForumTopic` | Закрывает General топик |
| `reopenGeneralForumTopic` | Открывает General топик |
| `hideGeneralForumTopic` | Скрывает General топик |
| `unhideGeneralForumTopic` | Показывает General топик |

## Как это работает в коде

### Создание топика

```python
import requests

BOT_TOKEN = "YOUR_BOT_TOKEN"
CHAT_ID = -1001234567890  # ID супергруппы

response = requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/createForumTopic",
    json={
        "chat_id": CHAT_ID,
        "name": "Домашние задания",
        "icon_color": 7322096,  # цвет иконки
    }
)

topic = response.json()["result"]
topic_id = topic["message_thread_id"]
print(f"Создан топик с ID: {topic_id}")
```

### Отправка сообщения в конкретный топик

```python
requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/sendMessage",
    json={
        "chat_id": CHAT_ID,
        "message_thread_id": topic_id,  # <-- вот это ключевое
        "text": "Привет, это сообщение в топике!"
    }
)
```

### Закрытие топика

```python
requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/closeForumTopic",
    json={
        "chat_id": CHAT_ID,
        "message_thread_id": topic_id
    }
)
```

## Ключевой параметр: `message_thread_id`

Каждый топик имеет свой `message_thread_id`. Этот ID нужно передавать в методы `sendMessage`, `sendPhoto`, `sendDocument` и т.д., чтобы сообщение попало **именно в нужный топик**, а не в General.

Когда бот получает сообщение из топика, в объекте `Message` будет поле `message_thread_id` — по нему можно понять, из какого топика пришло сообщение.

## Доступные цвета иконок

Telegram разрешает только определённые цвета для иконок топиков:
- `7322096` (синий)
- `16766590` (жёлтый)
- `13338331` (фиолетовый)
- `9367192` (зелёный)
- `16749490` (красный)
- `16478047` (оранжевый)

## Требования

- Группа должна быть **супергруппой**
- У группы должны быть **включены темы** (Topics)
- Бот должен иметь права **администратора** с разрешением `can_manage_topics`

## Итого

**Прикол топиков** в том, что они превращают обычный групповой чат в мини-форум. Бот может автоматически создавать структуру обсуждений, маршрутизировать сообщения по категориям, строить тикет-системы — и всё это внутри одного Telegram-чата, без необходимости создавать десятки отдельных групп.
