# Топики (Forum Topics) в Telegram Bot API

## Два режима топиков

Топики в Telegram работают в **двух** местах:
1. **В супергруппах** — классический вариант, давно существует
2. **В личном чате с ботом** — новая фича, именно её ты видишь

---

## Топики прямо в личке у бота — что это?

Когда открываешь такого бота, вместо обычного плоского чата видишь **список тем** (как форум). Нажимаешь на тему — проваливаешься внутрь и общаешься с ботом только в рамках этой ветки.

### Как это выглядит
```
┌─────────────────────────┐
│  🤖 SomeBot             │
├─────────────────────────┤
│  📦 Мои заказы          │
│  💬 Поддержка           │
│  ⚙️ Настройки           │
│  📝 История             │
│  ➕ Новая тема...       │
└─────────────────────────┘
```

Вместо одной длинной переписки — отдельные ветки, каждая со своей историей.

### Как владелец бота это включает

Через **BotFather**:
1. Открываешь @BotFather
2. `/mybots` → выбираешь бота → **Bot Settings** → **Topics in Bot Chat**
3. Включаешь — и всё, у пользователей в чате с ботом появляются топики

Или программно через API — устанавливаешь нужные настройки чата.

### Зачем это боту в личке?

**Проблема без топиков:** всё в одной куче. Спросил про заказ, потом задал вопрос поддержке, потом настроил уведомления — и вся эта каша в одном чате. Ищи потом нужное сообщение.

**С топиками:**

| Топик | Что внутри |
|---|---|
| 📦 Заказ #1234 | Вся переписка по заказу |
| 📦 Заказ #5678 | Другой заказ — отдельно |
| 💬 Вопрос по оплате | Общение с поддержкой |
| ⚙️ Настройки | Настройка бота |

Каждый разговор — в своём месте. Не перемешивается.

### Реальные примеры ботов с топиками в личке

- **Саппорт-боты** — каждый тикет = отдельный топик. Закрыли тикет — закрыли топик.
- **Магазины/доставка** — каждый заказ = отдельный топик. Статус, трекинг, вопросы по заказу — всё в одном месте.
- **AI-боты (ChatGPT-обёртки)** — каждая тема разговора = отдельный топик. Как «чаты» в ChatGPT, но внутри Telegram.
- **Финансовые боты** — отдельные топики для портфеля, алертов, истории сделок.
- **Учебные боты** — топик на каждый урок/курс/предмет.

## Как это работает технически

### Ключевой параметр: `message_thread_id`

Каждый топик имеет уникальный `message_thread_id`. Бот получает это поле в каждом входящем сообщении и знает, **из какого топика** пришло сообщение. При ответе передаёт тот же `message_thread_id`, чтобы ответ попал в нужный топик.

### Создание топика в личке бота

```python
import requests

BOT_TOKEN = "YOUR_BOT_TOKEN"
USER_CHAT_ID = 123456789  # ID чата с пользователем

response = requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/createForumTopic",
    json={
        "chat_id": USER_CHAT_ID,
        "name": "Заказ #1234",
        "icon_color": 7322096,
    }
)

topic = response.json()["result"]
topic_id = topic["message_thread_id"]
```

### Отправка сообщения в конкретный топик

```python
requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/sendMessage",
    json={
        "chat_id": USER_CHAT_ID,
        "message_thread_id": topic_id,  # <-- сообщение попадёт в нужный топик
        "text": "Ваш заказ #1234 отправлен!"
    }
)
```

### Обработка входящих сообщений из топика

```python
def handle_update(update):
    message = update.get("message", {})
    thread_id = message.get("message_thread_id")
    
    if thread_id:
        # Сообщение пришло из конкретного топика
        print(f"Топик: {thread_id}, текст: {message['text']}")
    else:
        # Сообщение из General (основной чат)
        print(f"Общий чат: {message['text']}")
```

### Закрытие/удаление топика

```python
# Закрыть (нельзя писать, но видно)
requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/closeForumTopic",
    json={"chat_id": USER_CHAT_ID, "message_thread_id": topic_id}
)

# Удалить полностью (вместе с сообщениями)
requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/deleteForumTopic",
    json={"chat_id": USER_CHAT_ID, "message_thread_id": topic_id}
)
```

## Все методы API для топиков

| Метод | Что делает |
|---|---|
| `createForumTopic` | Создаёт новый топик |
| `editForumTopic` | Меняет название и иконку |
| `closeForumTopic` | Закрывает (нельзя писать) |
| `reopenForumTopic` | Открывает обратно |
| `deleteForumTopic` | Удаляет вместе с сообщениями |
| `unpinAllForumTopicMessages` | Открепляет все сообщения в топике |
| `getForumTopicIconStickers` | Список стикеров для иконок |
| `editGeneralForumTopic` | Редактирует General топик |
| `closeGeneralForumTopic` | Закрывает General |
| `reopenGeneralForumTopic` | Открывает General |
| `hideGeneralForumTopic` | Скрывает General |
| `unhideGeneralForumTopic` | Показывает General |

## Топики в супергруппах (классический вариант)

Это более старая фича — топики внутри групповых чатов. Работает так же технически (`message_thread_id`), но включается в настройках группы, а не бота.

**Применение в группах:**
- Бот-модератор создаёт тематические ветки
- Бот-нотификатор раскидывает алерты по категориям
- Тикет-система: топик на каждого пользователя

**Требования для групп:**
- Группа должна быть **супергруппой**
- Включена настройка **«Темы»** (Topics)
- Бот — **администратор** с разрешением `can_manage_topics`

---

## Итого

**Прикол топиков в боте** — это по сути **папки/вкладки внутри чата с ботом**. Вместо одной бесконечной переписки бот (или ты сам) создаёт отдельные ветки под разные задачи. Каждая ветка — изолированный диалог со своей историей.

Это как если бы вместо одного чата с ботом у тебя было 10 отдельных чатов, но всё организовано в одном месте.

Фича особенно полезна для ботов, которые делают **много разных вещей** — вместо меню и /команд для переключения контекста, у тебя просто разные топики для разных задач.
