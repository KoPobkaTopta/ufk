# Учебный плакат «Штурм строения» 60 × 90 см

Плакат по тактической подготовке для занятия на полигоне (учебный тактический
дом — деревянный сруб). Генерируется скриптами, готовые файлы лежат в `out/`.

Материал **учебно-методический**: он предназначен для проведения занятий по
общевойсковой тактической подготовке и для разбора типовых ошибок. Порядок
действий уточняется по обстановке и решению командира; меры безопасности
доводятся под роспись до начала занятия.

## Что внутри

| Файл | Что это |
| --- | --- |
| `out/shturm_doma_60x90.xlsx` | Плакат в Excel: лист-холст `ПЛАКАТ 60x90` плюс рабочие таблицы |
| `out/shturm_doma_60x90.pdf` | Готовый к печати файл, размер страницы ровно 600 × 900 мм |
| `out/shturm_doma_60x90.svg` | Векторный оригинал (можно править в Inkscape / Illustrator) |
| `out/shturm_doma_60x90_preview.png` | Растровый предпросмотр |

### Лист «ПЛАКАТ 60x90»

Это именно плакат, а не таблица: 120 столбцов × 180 строк, каждая ячейка —
квадрат 5 мм, итого 60 × 90 см. Схема дома нарисована заливками ячеек
в масштабе 1:50 — одна ячейка равна 0,25 м, то есть толщине стены из бруса.

Печать: `Файл → Печать`, лист уже настроен на «вписать в одну страницу»,
поля минимальные. Для печати в реальный размер в свойствах принтера/плоттера
нужно выбрать бумагу 600 × 900 мм (или напечатать `.pdf`, где размер
страницы задан точно).

### Остальные листы книги

`Расчёт`, `Этапы`, `Секторы`, `Приёмы`, `Чек-лист`, `Источники` — те же данные
обычными таблицами: их удобно править, печатать раздаточным материалом
и вести по ним занятие.

## Содержание плаката

- схема объекта: три входа, за каждым тамбур, справа «змейка» из пяти колен,
  левее — сквозной коридор до тыльной стены;
- боевой расчёт: 8 человек — две тройки стрелков (АК, магазин на 30 патронов,
  дымовая шашка на каждого), пулемётчик справа, гранатомётчик слева;
- оси движения, рубежи, накопление у стены, дымовая завеса, секторы огня
  средств поддержки, рубеж перехода в атаку;
- восемь этапов от выдвижения до закрепления;
- способы входа в проём «крюк» и «крест» с мини-схемами;
- поле видимости, мёртвые зоны, порядок работы по коленам и в коридоре;
- меры безопасности и список руководящих документов.

## Пересборка

```bash
pip install -r requirements.txt
python3 build.py            # результат в out/
```

Служебные скрипты для проверки вёрстки, в печать не идут:

```bash
python3 crop_preview.py 12 150 390 360 plan 1400   # фрагмент SVG в PNG (мм)
python3 preview_xlsx.py xlsx_full 1200             # лист Excel в PNG
```

## Структура кода

```
generator/plan.py         геометрия дома и маршрутов, в метрах
generator/content.py      весь текст: этапы, приёмы, расчёт, источники
generator/style.py        палитра
generator/canvas_xlsx.py  «холст» поверх листа Excel: заливки, стрелки, текст
generator/xlsx_poster.py  сборка плаката и таблиц в .xlsx
generator/svgkit.py       минимальный конструктор SVG в миллиметрах
generator/svg_poster.py   сборка векторного плаката 600 × 900 мм
```

Планировка задаётся в `plan.py` в метрах, поэтому обе версии плаката рисуют
один и тот же дом. Если реальный дом на полигоне отличается — правятся
константы `WIDTH`, `DEPTH`, `MODULE_W`, `SNAKE_WALLS`, `LINK_OPENINGS`,
и обе версии перестраиваются одной командой.
